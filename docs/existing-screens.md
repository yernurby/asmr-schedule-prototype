## Экраны

### 1. Панель администратора — `screen-01`
**Роль:** админ. **Путь:** «Панель».
Карточка «Быстрый доступ» с кнопками-ярлыками (Заказы, Возвраты, Группы,
Просмотр зачислений, Транзакции, Управление пользователями, Управление курсами;
первая — основная, остальные вторичные).
Карточка «Очередь ожидания» с KPI-числом (398) и ссылкой
«Перейти к ожидающим зачислениям».

### 2. Студенты — `screen-02`
**Роль:** админ. **Путь:** Пользователи → Студенты.
Кнопки: Bulk import, Массовая синхронизация Moodle, Clear students import data
(деструктивная), Новый студент (основная).
Строка поиска «Поиск по ФИО, e-mail, телефону, родителю, школе или городу» + «Поиск».
Панель «Фильтры 0».
Таблица: СТУДЕНТ · КОНТАКТЫ (e-mail + телефон) · ДАННЫЕ РОДИТЕЛЯ (ФИО + телефон) ·
ЛОКАЦИЯ · MOODLE (пилюля «Связан (#8441)» / «Ожидает синхронизации» + ссылка
«Повторить синхронизацию») · ЗАЧИСЛЕНИЯ (пилюли «N активный», «N ожидает») ·
ДЕЙСТВИЯ («Редактировать»).

### 3. Детали студента — `screen-03`, `screen-04`
**Роль:** админ. Открывается из списка студентов.
Кнопка «Назад» слева от заголовка, «Редактировать студента» справа.
Блоки: Информация о студенте (имя, e-mail, телефон, Telegram-ник, город, класс,
школа, год выпуска, Level Test, результаты тестов) · Информация о родителях ·
Заказы (карточки заказов со статусом) · Запросы на возврат ·
Зачисления по курсам (две таблицы: активные — курс/группа/статус/«Перевести»;
ожидающие — курс/статус/заметка) · История переводов между группами.

### 4. Детали студента — куратор — `screen-32`, `screen-33`
**Роль:** куратор. То же, что у админа, плюс форма «Создать запрос на возврат»
(заказ, конкретные курсы, причина, комментарий, «Отправить запрос»).
В истории переводов видно «Переведен из NU JOURNEY AUGUST в NU JOURNEY 9.1».

### 5. Сотрудники (Staff) — `screen-05`, `screen-06`
**Роль:** админ. **Путь:** Пользователи → Сотрудники.
Интерфейс частично на английском («Staff», «View and manage staff members.»).
Вкладки-роли: All Staff · Admin · Sales · Curator · Finance · Quality Control Head ·
Academ Head · Sales Head · Marketing Head · Transitional Head · Operational Head ·
Teacher · HR. Счётчик «Total: 38».
Таблица: NAME · ROLE (пилюли ролей) · EMAIL (+ строка «Moodle: linked (#492)» /
«Moodle: pending») · PHONE · STATUS · ACTIONS (Edit, Deactivate, Moodle sync, Delete).

### 6. Модалка «Create staff user» — `screen-07`
Поля: First name, Last name, Email, Phone (с флагом страны), Roles (12 чекбоксов
в 2 колонки, первая выбранная роль — основная), Status, Password, Telegram nick,
Teacher profile (Short bio, Years of experience). Футер: Cancel / Create user.

### 7. Заказы — `screen-08`
**Роль:** админ. Поиск + Фильтры.
Таблица: ID ЗАКАЗА · СТУДЕНТ · ПРОДУКТ · ИТОГО · ОПЛАЧЕНО · СТАТУС
(Оплачен / Частично оплачен) · ДАТА ЗАКАЗА · ДЕЙСТВИЯ («Детали»). Суммы в KZT.

### 8. Детали заказа — `screen-09`, `screen-10`, `screen-11`
**Роль:** админ. Кнопки: Скопировать данные, Редактировать, Изменить сумму,
Отметить как созданный по ошибке.
Три карточки: Информация о заказе (общая/оплаченная/возвращено/чистая сумма, МОП,
путь клиента, статус, остаток, даты, ссылка на AmoCRM) · Информация о студенте ·
Детали продукта (список курсов со статусами «Активен»/«Ожидает», «Заменить курс»,
«Удалить», «+ Добавить курс»).
Ниже: История заказа · Платежи (сумма, метод Kaspi Kredit, распределение продажи
между МОПами, квитанции, загрузка файлов) · Добавить платёж (сумма, метод, заметка,
дата, файлы, разделение оплаты) · Создать тикет на возврат · Запросы на возврат ·
Вложения (Квитанции / Договоры) · Зачисления по курсам.

### 9. Курсы — `screen-12`
**Роль:** админ. Кнопки: Bulk import, Новый курс.
Таблица: ID (моноширинный ObjectId) · НАЗВАНИЕ · ОПИСАНИЕ · СТАТУС
(Активный / Архивный) · ДЕЙСТВИЯ (Редактировать, Архивировать / Активировать).
Курсы: INDIV, Pre-IELTS (NU JOURNEY), Pre-IELTS (VIP), Pre-IELTS (IELTS EXPLORER),
Pre-IELTS (RTN), SAT, IELTS, NUET.
> **У курса нет предметов** — это ровно то, что добавляет часть 1.

### 10. Продукты — `screen-13`, `screen-14`
**Роль:** админ. Таблица: ID · НАЗВАНИЕ · ЭЛЕМЕНТЫ (нумерованный список курсов) ·
СТАТУС (+ подпись «Structure locked after sales») · ДЕЙСТВИЯ.
Продукты — это наборы курсов в заданной последовательности
(IELTS JOURNEY, ROAD TO NU (SAT) + NUET YEAR, COMBO GRANT, NUET LEGEND и т. д.).

### 11. Группы — `screen-15`, `screen-16`, `screen-17`
**Роль:** админ. **Ключевой экран для нашего модуля.**
Вкладки-фильтры: Все группы (323) · Идет набор + активные (29) ·
Не идет набор + активные (123) · Идет набор + не активные (0) ·
Не идет набор + не активные (171).
Поиск по названию + фильтры: Все курсы, Все преподаватели, Все кураторы,
Заполненность, Быстрый период, Старт с/по, Конец с/по. Кнопка «Столбцы».
Таблица сгруппирована по курсу цветными полосами (IELTS (155), PRE-IELTS (RTN) (3),
NUET (4) и т. д.). Колонки: НАЗВАНИЕ (со звездой избранного) · КУРС ·
ВМЕСТИМОСТЬ (пилюля 5/15) · ЗАМЕТКИ · НАЧАЛО · КОНЕЦ · ДЛИТЕЛЬНОСТЬ (8 нед.) ·
**РАСПИСАНИЕ** · ПРЕПОДАВАТЕЛИ · КУРАТОРЫ · НАБОР (Открыт/Закрыт) ·
ДЕЙСТВИЯ (Редактировать / Архивировать).
> **Расписание здесь — просто текст**: «Пн 19:30-21:00 / Ср 19:30-21:00 / …».
> Не видно, какой предмет и кто ведёт конкретный день. Занятий за этим нет.
> Это и есть исходная проблема, которую закрывает модуль.

### 12. Карточка группы — `screen-18`
**Роль:** админ. «Назад», заголовок, «Редактировать».
Четыре статистические карточки: Вместимость (5/15) · Дата начала · Статус · Набор.
Блоки: Документы группы (КП / КТП — «Не прикреплено») · Заметки (+ ссылка на
Telegram-группу) · Список студентов (таблица: СТУДЕНТ · EMAIL · ТЕЛЕФОН · СТАТУС ·
ДЕЙСТВИЯ «Перевести», кнопка «Колонки»).
> В карточке группы **нет ни расписания как объектов, ни занятий, ни посещаемости**.

### 13. Карточка группы — куратор — `screen-31`
**Роль:** куратор. То же плюс блок «Детали группы»: курс, преподаватели,
длительность, расписание (снова текстом: «Пн 17:00-18:00 / Ср / Пт»).
Статистических карточек три: Вместимость, Дата начала, Статус.

### 14. Модалка «Создать группу» — `screen-19`, `screen-20`
**Роль:** админ. Поля: Название · Заметки · Ссылка на Telegram-группу · Курс ·
Дата начала · Дата окончания · Вместимость · **Расписание («Add schedule row»)** ·
Преподаватели (мультиселект с поиском) · Кураторы (мультиселект) ·
Открыт для набора (чекбокс) · Документы группы (КП, КТП — загрузка файлов).
Футер: Отмена / Сохранить.
> Расписание задаётся строками «день + время», без предмета и без преподавателя
> на конкретный день. Часть 2 меняет именно это.

### 15. Зарплата Академа — Преподаватели — `screen-21`, `screen-22`
**Роль:** админ. **Ключевой экран для части 6.**
Вкладки: Преподаватели · Кураторы · Академ Хэд · Настройки.
Шапка: «Выплаты — 2026-08», выбор месяца, «Синхронизировать группы»,
«Заморозить месяц» (зелёная). Статистика: Преподавателей 29, Фонд ЗП ₸0.
Таблица: ФИО · ПРЕДМЕТЫ / ГРУППЫ (например «SAT ×1, Pre-IELTS (VIP) ×2») ·
**КОЛ-ВО УРОКОВ** · СТАТУС (Черновик / Подтверждено) · ИТОГО ЗП.
Раскрытая строка преподавателя: по каждому курсу базовая ставка/час, по каждой
группе — своя ставка, **«Уроки 1ч» и «Уроки 1.5ч» — поля, заполняемые вручную**,
база, аттенданс %, бонус 5%. Ниже: Проверка моков, Доп. бонусы и штрафы,
итоговая строка (База за уроки, Бонус аттенданс, Проверка моков, Доп. бонусы,
Штрафы, Официалка, Нал после 1% налога, Итого начислено).
> **Количество уроков вбивается руками.** Часть 6 подставляет сюда факт.

## Что из этого важно для модуля расписания

| Наблюдение | Часть модуля |
|---|---|
| У курса нет предметов — только название | 1 |
| Расписание группы — строка «Пн 19:30-21:00», без предмета и преподавателя | 1, 2 |
| За расписанием нет объектов-занятий: нечего открыть, отменить, перенести | 2 |
| Пункт «Календарь» в меню есть, но экрана нет; занятость людей нигде не видна | 3 |
| Посещаемость: «Отчет по посещаемости будет добавлен позже» | 4 |
| Замены и переносы в системе не отражены вообще | 5 |
| «Уроки 1ч» / «Уроки 1.5ч» в зарплате — поля ручного ввода | 6 |
