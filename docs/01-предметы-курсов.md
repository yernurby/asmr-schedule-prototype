Модуль «Курсы» — предметы Part 1.

## Задача

Сейчас у курса нет понятия «предмет». Для IELTS это не мешает — там один предмет, один преподаватель, одно расписание. Но у SAT два предмета (Math и Verbal) с разными преподавателями, у NUET два (математика и критическое мышление), у ЕНТ — до пяти. Развести расписание внутри одной группы сейчас невозможно, и непонятно, за какой именно урок платить преподавателю.

## Что добавить в курсы

1. При создании курса и при редактировании существующего добавить блок «Предметы».
2. Названия предметов пишутся вручную, никакого готового списка не нужно. Курс может состоять минимум из одного предмета и максимум из десяти.
3. Предметы можно добавлять, переименовывать и архивировать. Удалить предмет, по которому уже стоит расписание в какой-либо группе, нельзя — только архивировать.
4. У курса не может быть ноль предметов. При создании нового курса автоматически создаётся один предмет с названием самого курса — если предметов больше не нужно, пользователь просто ничего не трогает.
5. Предметы принадлежат конкретному курсу и не пересекаются между курсами. «Математика» в NUET и «Math» в SAT — это две отдельные записи, а не одна общая. Содержание разное, преподаватели разные.

## Что добавить в карточку сотрудника

6. У преподавателя добавить поле «Предметы» — можно отметить несколько, в том числе из разных курсов. Показывать это поле только для роли Teacher.

Дальше это будет использоваться в двух местах: при постановке преподавателя в расписание и при поиске, кто может подменить.

## Что меняется в группах

8. При создании и редактировании группы расписание задаётся отдельно по каждому предмету курса. Строки расписания группируются по предметам, каждая группа сворачивается, чтобы форма не растягивалась.
9. В каждой строке расписания указывается: день недели, время начала, время конца, преподаватель и ссылка на Meet.
10. Преподаватель ставится на каждый предмет отдельно. При выборе преподавателя в списке сначала показываются только те, у кого этот предмет отмечен в карточке, плюс кнопка «показать всех» — на случай, если нужен кто-то ещё.
11. Если у курса всего один предмет, никакой группировки не показывать. Строки идут обычным списком, как сейчас.
12. Поле «Преподаватели» в шапке группы сделать нередактируемым — пусть собирается автоматически из строк расписания.

Сейчас это отдельный список, который заполняется руками. Если оставить как есть, получится два источника правды: в шапке выбран один человек, в расписании стоит другой. Кто прав — непонятно, и зарплата посчитается не тому.

Кураторы остаются как были, отдельным полем, их по-прежнему выбирают вручную.

## Что меняется в отображении

13. В списке групп в колонке «Расписание» рядом с каждой строкой показывать предмет и преподавателя. Например:

```
Пн 15:00–16:30 · Матем · Аскар Ж.
Чт 15:00–16:30 · Матем · Аскар Ж.
Вт 17:00–18:30 · Крит · Дильназ С.
Пт 17:00–18:30 · Крит · Дильназ С.
```

14. Для курсов с одним предметом предмет не выводить — только время и преподавателя, как сейчас.
15. В списке курсов добавить колонку с предметами курса.
16. В фильтрах списка групп добавить фильтр по предмету.

## Перенос существующих данных

17. Всем существующим курсам создать по одному предмету с названием курса.
18. Для NUET, SAT и ЕНТ академический директор добавляет остальные предметы вручную и расставляет преподавателей.
19. Поле «Предметы» у преподавателей заполняется вручную.

## Как понять, что готово

Предмет можно добавить, переименовать и заархивировать. Больше десяти добавить нельзя. Предмет с привязанным расписанием не удаляется. У курса с одним предметом на экранах ничего не изменилось. У преподавателя можно отметить несколько предметов из разных курсов. В строке расписания есть предмет и преподаватель. Список преподавателей фильтруется по предмету, есть «показать всех». Поле «Преподаватели» в шапке группы считается само. В списке групп видно, кто какой предмет ведёт и когда.
