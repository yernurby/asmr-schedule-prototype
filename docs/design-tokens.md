# Design tokens АСМР

Источник: 39 скриншотов реальной системы в `reference/screens/`.
Все значения ниже **сняты пиксельно** с этих скриншотов (сэмплирование цвета,
измерение высот текста, границ, скруглений), а не подобраны на глаз.

Скриншоты сделаны 1:1 (монитор 2560×1440, масштаб 100%), поэтому измеренные
пиксели = CSS-пиксели.

> Правило: в прототипе используются **только** значения из этого файла.
> Новых цветов, радиусов и шрифтов не вводить.

---

## 1. Палитра

Система построена на стандартной палитре Tailwind (`slate` как нейтральная,
`emerald` / `amber` / `red` как акценты). Все значения совпадают со стоковыми
токенами Tailwind — значит, в прототипе можно писать `bg-slate-50`, `text-slate-900`
и т. д. без кастомного конфига.

## 3. Скругления

Замерено по кривизне углов (пиксельный обход контура).

|---|---|
| Карточка / панель | 6px (`rounded-md`) |
| Кнопка (основная и вторичная) | 6px (`rounded-md`) |
| Поле ввода, select, textarea | 6px (`rounded-md`) |
| Вкладка-таблетка (фильтры-табы) | 6px (`rounded-md`) |
| Модальное окно | 8px (`rounded-lg`) |
| Пилюля статуса | полное скругление (`rounded-full`) |
| Активный пункт левого меню | 6px (`rounded-md`) |

Других радиусов в системе нет.

## 5. Кнопки

**Основная (primary)**
`bg: #0F172A` · `text: #FFFFFF` · радиус 6px · высота 34px · 14px medium
Примеры: «Новый студент», «Новая группа», «Новый курс», «Create staff user»,
«Добавить платёж», «Сохранить», «Отправить запрос».

**Вторичная (secondary)**
`bg: #FFFFFF` · `border: 1px #CBD5E1` · `text: #334155` · радиус 6px · высота 34px
Примеры: «Bulk import», «Назад», «Отмена», «Столбцы», «Колонки», «Перевести».

**Успех (success)** — редкая, только для «зафиксировать/подтвердить»
`bg: #059669` · `text: #FFFFFF`
Пример: «Заморозить месяц».

**Деструктивная (danger)** — только контурная
`bg: #FFFFFF` · `border: 1px #BE123C` · `text: #BE123C`
Примеры: «Delete», «Clear students import data».

**Ссылка-действие в таблице**
без фона, 14px, подчёркнута. Цвета по смыслу:
нейтральное — `#334155` («Редактировать», «Детали»),
разрушающее — `#DC2626` («Архивировать», «Аннулировать платёж»),
восстанавливающее — `#059669` («Активировать»).

**Вкладки-фильтры (таблетки)**
активная: `bg #0F172A`, текст белый;
неактивная: `bg #FFFFFF`, `border 1px #CBD5E1`, текст `#334155`.
Пример: «Все группы (323) / Идет набор + активные (29) / …», роли в Staff.

**Вкладки-разделы (подчёркнутые)**
На экране «Зарплата Академа»: «Преподаватели / Кураторы / Академ Хэд / Настройки».
Активная — тёмный текст `#0F172A`, неактивная — `#64748B`.

## 6. Пилюли статусов

Все пилюли: `rounded-full`, высота 23px, 12px medium, padding 2px / 10px.

| Значение | Фон | Текст | Где |
|---|---|---|---|
| `Активный`, `active`, `Открыт`, `Оплачен`, `Active`, `Связан (#8441)` | `#D1FAE5` | `#047857` | статусы курсов, групп, заказов, Moodle |
| `pending`, `Ожидает`, `Частично оплачен`, `1 ожидает`, `Ожидает синхронизации`, `Данные ещё не предоставлены`, `Teacher` | `#FEF3C7` | `#B45309` | ожидание, частичная оплата, роль-тег |
| `Архивный`, `Уровень 1` | `#F1F5F9` | `#64748B` | архив, нейтральные метки |
| `Подтверждено` | `#EFF6FF` + рамка `#BFDBFE` | синий | статус выплаты |
| `Quality Control Head` и др. роли-теги | `#FEE2E2` | `#BE123C` | вторая роль сотрудника |

**Пилюля заполняемости группы** (`5/15`, `14/15`, `17/17`) — та же форма,
цвет по заполненности: свободно — зелёная, почти полная — жёлтая,
полная/переполненная — красная (`#FEE2E2`).

## 7. Таблицы

- Обёртка: белая карточка, граница `#E2E8F0`, радиус 6px.
- Шапка: фон `#F8FAFC`, текст 12px UPPERCASE `#64748B`, снизу 1px `#E2E8F0`.
- Строки: белый фон, разделитель 1px `#F1F5F9`.
- Ячейки: padding 12px по вертикали, 16px по горизонтали.
- Двухстрочная ячейка (например e-mail + телефон): вторая строка 12px `#64748B`.
- Последняя колонка «ДЕЙСТВИЯ» — ссылки-действия, выравнивание по левому краю колонки.
- **Полоса-группировка**: в списке групп строки сгруппированы по курсу; над
  группой — цветная полоса во всю ширину таблицы с названием курса и счётчиком:
  IELTS — `#FECACA` / текст `#7F1D1D`; Pre-IELTS — `#FDE68A`; NUET — `#A7F3D0`.
- **Избранная строка** (со звездой `#F59E0B`): фон `#FFFBEB`.
- Счётчик записей — справа над таблицей, 14px `#64748B`.

## 8. Формы и модальные окна

**Модальное окно**
Оверлей `rgba(0,0,0,0.30)`; окно белое, ширина 512px, радиус 8px, отступ сверху 79px.
Заголовок 20px semibold слева, крестик закрытия справа.
Тело прокручивается при переполнении.
Футер справа: «Отмена» (вторичная) + основная кнопка («Сохранить», «Create user»).

**Поля**
- Подпись сверху, 14px `#334155`, отступ 6px до поля.
- Поле: белый фон, граница 1px `#E5E7EB`, радиус 6px, высота 38px, текст 14px,
  плейсхолдер `#94A3B8`.
- `textarea` — та же граница, высота по содержимому (мин. 2–3 строки).
- Подсказка под полем — 12px `#64748B`
  («Необязательно. Должна начинаться с https://t.me/»).
- Чекбоксы — стандартные, подпись 14px справа; сетка в 2 колонки (роли в форме сотрудника).
- Мультиселект (преподаватели/кураторы): поле поиска + прокручиваемый список
  чекбоксов в рамке, сверху счётчик «0 selected» и ссылки «Select filtered / Clear».

**Информационные плашки внутри страницы**
- Информация: фон `#EFF6FF`, текст синий, 14px, радиус 6px, padding 12px.
- Блокировка/предупреждение: фон `#F1F5F9`, текст `#334155`, с иконкой замка.

## 10. Чего в скриншотах нет

Ниже перечислено то, для чего в реальной системе не нашлось образца.
Прежде чем это рисовать, нужно спросить заказчика.

- Календарная сетка (месяц / неделя / день) — раздела «Календарь» в меню видно,
  но ни одного скриншота самого календаря нет.
- Состояния наведения (hover) и фокуса — на статичных скриншотах не видны.
  Предполагаем hover строк `#F8FAFC`, фокус — стандартное кольцо Tailwind.
- Тосты/уведомления об успехе и ошибке.
- Пустые состояния — есть только текстовые («Запросов на возврат пока нет.»,
  `#64748B`, 14px), без иллюстраций.
- Тёмная тема — отсутствует, система только светлая.
- Мобильная/адаптивная версия — все скриншоты десктопные, 2557px шириной.
