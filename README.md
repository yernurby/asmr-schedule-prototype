# АСМР · Модуль расписания — интерактивный прототип

Прототип нового модуля расписания для **АСМР** — внутренней CRM/LMS
образовательной компании WeGlobal (Казахстан: IELTS, SAT, NUET, ЕНТ).

**Живая версия:** https://yernurby.github.io/asmr-schedule-prototype/

Это не продакшн и не статичный мокап. Прототип работает: данные живут в
браузере, изменения сохраняются, роль и «текущее время» переключаются в шапке.

## Зачем он нужен

Сегодня расписание группы в АСМР хранится текстом — строкой вида
«Пн 17:30–19:00». Из неё непонятно, какой предмет и кто ведёт. За ней не стоит
никаких занятий: нельзя открыть конкретный урок, отменить, перенести или
посчитать. Календаря нет. Замены обсуждаются в чатах. Количество проведённых
уроков в зарплату вбивается вручную, со слов преподавателей.

Прототип показывает разработчику и академическому директору логику будущего
модуля до начала реальной разработки.

## Модуль состоит из шести частей

| № | Часть | Статус |
|---|---|---|
| 1 | Предметы у курсов | не начата |
| 2 | Занятия и изменение расписания | не начата |
| 3 | Календари и доступность | не начата |
| 4 | Посещаемость | не начата |
| 5 | Замены и переносы | не начата |
| 6 | Зарплата по факту занятий | не начата |

Актуальный статус — на странице **«Карта модуля»** внутри прототипа.

## Запуск локально

```bash
npm install
npm run dev
```

```bash
npm run build
```

```bash
npm run seed
```

Последняя команда пересобирает `src/data/seed.json` из
`scripts/generate-seed.mjs`. Генератор детерминированный: повторный запуск даёт
байт-в-байт тот же файл.

## Что где лежит

| Путь | Что это |
|---|---|
| `docs/` | Тексты ТЗ и рабочие документы. Читаются прямо в прототипе на странице «Требования» |
| `docs/design-tokens.md` | Цвета, шрифты, размеры — сняты пиксельно со скриншотов реальной системы |
| `docs/existing-screens.md` | Опись всех экранов АСМР, которые видно на скриншотах |
| `reference/screens/` | 39 скриншотов реальной АСМР |
| `src/ui/` | UI-примитивы строго по токенам |
| `src/app/` | Каркас: меню, шапка, роутер |
| `src/pages/` | Экраны |
| `src/data/` | Типы, seed, карта модуля |
| `src/store/` | Zustand-хранилища: данные и сессия |

Подробнее об архитектуре и соглашениях — в [CLAUDE.md](CLAUDE.md).

## Публикация

Пуш в `main` → GitHub Actions собирает и публикует на GitHub Pages.
Ссылка не меняется.

Vite настроен с `base: '/asmr-schedule-prototype/'`, роутер — `HashRouter`,
поэтому прямые ссылки на страницы работают.
